# RX-001 — 建築研究を計算統計的Corpus研究として捉える

## Source
- Research Council #27
- LAB-RQ #26
- RQ-001 Architecture Corpus
- RQ Theme Tracker #24

## Observation
AI / BIM / CAD / mesh / Visualization / BQML / LLM / Agent / BATTA は、研究対象そのものではなく、建築研究Corpusを観測・変換・分析する手段として配置できる。

論文・研究発表タイトルCorpusを年次・会議別に構造化し、頻度・共起・類似度・クラスタリング・embedding・theme transition・emerging / persistent / drift / gap を観測することで、建築研究のテーマ構造を計算統計的に記述できる可能性がある。

## Interpretation
建築を生成する研究から出発するのではなく、建築研究そのものを比較可能なCorpusとして観測し、そこから次の研究問いを発見する方向へ移行する。

統計的観測と建築学的解釈は分離する。

- Observation: Corpus上の語・クラスタ・テーマの増減、持続、移動、空白
- Interpretation: その変化を建築研究の変化としてどう意味づけるか

BQML / bqmlite-go は分析手段であり、研究対象ではない。

## Seminar
- 黒田: 建築作品だけでなく、建築について行われた研究活動そのものを研究対象として測れる。
- 佐伯: Corpus → 分析 → 観察 → RX → 次RQを基本ループにする。
- 神谷: タイトルCorpusは研究内容の真実ではなく、研究表象上の統計的パターンである。
- 三浦: タイトルだけで最小実験を行い、必要ならabstractやGeometryへ拡張する。
- 中野: Corpus外の研究をgapと呼ぶには、データ不足との区別が必要。

## Next Question
建築研究タイトルCorpusを用いて、テーマの出現・持続・ドリフト・空白を再現可能に測定できるか？
