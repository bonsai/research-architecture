# RQ-009 — 建築を時間・身体・光・視点による経験として記述できるか

## Research Question
建築を静止した物体ではなく、時間・身体・光・視点によって変化する経験として、アニメーションで記述できるか。

## Hypothesis
**H1:** 静止画・平面図・断面図・静的3Dだけでは表現しにくい時間的・身体的・視点依存の関係を、建築アニメーションは追加的に観察可能にする。

## Antithesis
**H0:** アニメーションは単なる視覚化手段であり、平面図・断面図・静的3Dで得られる建築的知識を本質的には増やさない。

## Object
- 建築空間
- CAD/BIM geometry
- 身体・人の移動
- 光・影
- 視点・カメラ
- 時間的変化

## Method
`CAD/BIM → Geometry → Temporal Transformation → Animation → Observation → RX → Evidence → Evaluation`

比較対象:
- plan
- section
- elevation
- static 3D
- temporal animation

## Observation schema
各観察は次を記録する。

- observer
- view_type
- frame/time
- spatial_relation
- relation_noticed
- interpretation
- confidence
- counterexample

## Falsification
以下のいずれかが確認された場合、H1を弱める・限定する・棄却する。

1. animationで追加的に発見される建築的関係がない
2. 発見された関係が既存図面から同等に取得できる
3. 観察者間で再現可能な差が確認できない
4. animationが情報追加ではなく注意誘導による錯覚だけを生む

## Expected Output
- static-vs-temporal observation dataset
- reproducible animation manifest
- counterexamples
- evidence/evaluation
- thesis revision
