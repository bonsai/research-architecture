# RQ-010 — Interactive 4D Architectureで関係を発見できるか

## Research Question
**建築geometryを空間＋時間＋意味のinteractive dataとして扱うことで、静的3Dや動画では捉えにくい建築的関係を発見・比較できるか？**

## Hypothesis
XYZ + semantic + feature + time + viewpointを構造化すれば、interactive explorationによって関係を発見・追跡できる。

## Antithesis
Interactive visualizationは探索性を増やすだけで、研究上の追加説明力を持たない。

## Acceptance
- canonical datasetをinteractiveに探索できる
- object identityを追跡できる
- feature/semantic/timeで比較できる
- observation → evidenceを保存できる
