# Seminar — 建築研究ゼミナール

研究問い・概念・実験を横断して、テーマを混ぜながら議論する場所。

## Lab Personas

| Role | Persona | Role in discussion |
|---|---|---|
| 教授 | 黒田 | 問い・哲学・全体設計。前提を壊し、問いを大きくする |
| 副手 | 佐伯 | 実務・構造化・GitHub/Issue。議論を次の行動へ変換する |
| D1 | 神谷 | 理論・先行研究・反証。主張を疑い、境界条件を探す |
| M2 | 三浦 | 実装・実験・可視化。考える前に小さく作ってみる |
| B4 | 中野 | 素朴な疑問・違和感・飛躍。「そもそも？」で前提を壊す |

## Principle

**テーマを固定しない。**

建築、AI、GitHub、ゲーム、アイドル、素材、ファッション、映像などを自由に横断する。

専門分担ではなく、5つの視点を混ぜることで新しい研究問いを発生させる。

## Discussion Flow

```text
テーマ
  ↓
5人で雑談
  ↓
問い / 仮説 / 違和感 / 反証 / 実装案
  ↓
新しい RQ
  ↓
RQ → EXT → EXP → RX → Evidence
  ↑
  └──── Seminar
```

## Session Record

Each session may record:

- Date
- Participants
- Topic(s)
- Related RQ / EXT / EXP
- Claims
- Questions
- Critiques / counterarguments
- Unexpected connections
- Decisions
- New RQ candidates
- Next actions

## Seminar is a feedback loop

`seminar/` is not a result archive and not an experiment implementation area.

It is the **research conversation layer** that feeds observations, criticism, and unexpected connections back into the research structure.

> ゼミは成果を保存する場所ではなく、研究構造を更新する場所。
